CSS selectors explained

To select the tag you only need to mention its name Tag selector
To select an id you need to put a '#' before its name Id selector
To select a class you must put a . before its name Class selector
To select a descendant you must a put a space between the names Descendants selector
To select a link put an 'a:' before its name Link selector
To select a child put a '>' after the one u want to focus on Child selector
To select a sibling put a '+' after the element of focus Sibling Selector
To select hover write 'a:hover' Hover Selector
To select visited write 'a:visited' Visited Selector
To select active write 'a:active' Active Selector

CSS vocabulary explained

Vocabulary Definitions Code Sample
CSS Absolute Units Absolute Units do not change when the screen size changes and are not recommended for websites. px - pixel, pt - point, pc - pica, in - inches, cm - centimeter, mm - millimeter, q - quarter.
CSS font family attribute The font family attribute functions by allowing user to change their font to their liking style = size:18px;
CSS padding With CSS you have full control over the padding there are properties for setting the padding for each side of an element div {padding: 50px 60px 20px 10 px}
CSS size viewpoint
  • vh {viewpoint height} 1vw equal 1% of the height of the viewpoint
  • vw {viewpoint width}: 1vw equals 1% of the width of the viewpoint
  • vmax; vmax equals 1% of the smaller value between the viewpoint width or height
  • vmin; vmin 1vmin equals 1% of the smaller value between the viewport width or height
 .centered {width: 60vw; height: 70vh;}
CSS visibility The visibility CSS property shows or hides an element without changing the space the element takes up. h3 {visibility: hidden; }
CSS Margin The CSS margin properties are used to create space around elements outside any defined borders div{margin:25px 50px 75px 100px}
CSS attribute font size Used to specify size(height) of the text within an element hl{font-size: 40px;}
CSS attribute: display CSS attribute called display alters an element and determines its position and type of box used on a webpage div{display: block;}
