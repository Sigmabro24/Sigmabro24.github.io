Loops

Loops in python are things that allow for a block of code to be executed repeatedly and there are two main types of loops in python such as:

While loop

A while loop will continuously happen as long as it remains true

For loop

A for loop will loop a sequence for a set amount of time

Differences

Despite both of them being python loops, while loops are used when there is an undefined ending like waiting for a user to input the right value while for loops are for when there is a defined end like looping until every item gets printed
