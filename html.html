HTML The html tag represents the root of an HTML document.
HEAD The head tag in HTML is an essential element used to define the head section of an HTML document. It is placed inside the tag, and used to store information that doesn't appear directly on the webpage itself.
TITLE A title tag is the clickable headline that appears on search engine results pages (SERPs), browsers, and social media platforms.
BODY All visible content goes here
IMG Displays images
NAV Navigates links
LINK creates a connection between the current document and an external source
